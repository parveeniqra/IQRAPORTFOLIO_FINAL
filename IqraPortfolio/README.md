# Iqra Parveen — Personal Portfolio

A responsive, multi-page personal portfolio built with HTML, CSS, and JavaScript.

## Run it
1. Extract `IqraPortfolio.zip`.
2. Open the extracted `IqraPortfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the **Live Server** extension and choose **Open with Live Server**.
4. Select **Explore My World** to open `portfolio.html`.

No npm install or build command is needed. Google Fonts, Font Awesome, and Tailwind CSS on the welcome page load from external CDNs. The supplied portrait and sunset landscape are bundled locally in `assets/images/`.

## Pages
- `index.html` — the submitted cinematic welcome screen, with its main button connected to the portfolio.
- `portfolio.html` — About, Skills, Projects, Learning Journey, values, and contact.

## Before publishing
- Check the LinkedIn button and replace its generic destination with your exact profile URL if needed.
- Replace the landscape image URLs with local assets if you want the site to work fully offline.
- Add project repositories only when they are ready to be shared.
- VoiceGuard AI is described as in development; no detection accuracy or finished AI model is claimed.
